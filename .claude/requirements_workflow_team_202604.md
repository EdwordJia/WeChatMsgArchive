### 需求3：会员ID系统 🆔

**优先级**: P1（支撑积分分配流程）  
**业务场景**: 总导演通过会员ID邀请成员，进行积分分配

#### 3.1 会员ID生成与管理

**ID格式设计**（需确认具体规则）：
```
可选方案：
1. 纯数字：8位或10位（如：10001234）
2. 前缀+数字：WF-10001234
3. 用户自定义ID（需唯一性校验）
```

**功能要求**：
- 每个会员注册时自动生成唯一ID
- 个人会员中心显示自己的ID
- 提供"一键复制ID"功能
- ID可用于邀请和查找会员

#### 3.2 会员邀请流程

```
总导演端（项目管理）:
1. 进入"项目管理 > 成员管理"
2. 点击"邀请会员"
3. 输入会员ID
4. 设置该成员在项目中的权限和初始积分额度
5. 发送邀请

被邀请会员端:
1. 收到邀请通知
2. 查看项目信息
3. 接受/拒绝邀请
4. 接受后加入项目，获得分配的积分额度
```

#### 验收标准

- [ ] 个人会员中心展示ID，支持一键复制
- [ ] 项目管理中可通过ID邀请会员

- [ ] 邀请流程完整，通知机制正常

### 需求4：积分分配管理系统 💰

**优先级**: P1（核心业务流程）  
**业务目标**: 实现"个人积分 → 项目子钱包 → 成员专属额度"的三级分配体系

#### 4.1 积分流转架构

```
┌─────────────────────────────────────┐
│            个人总账户                      │
│              (用户的积分总池)                  │
└────────────────────┬────────────────────────────────┘
                  │ 划拨
                 ↓
┌─────────────────────────────────────────────┐
│                 项目子钱包                             │
│              (项目专属积分池，总导演管理)                    │
└────────────────────┬─────────────────────────┘
                     │ 分配
                 ↓
┌───────────────────────────────────────────────┐
│            成员专属额度                                │
│           (项目成员可使用的积分额度)                    │
└───────────────────────────────────┘
```

#### 4.2 积分划拨功能（总导演操作）

**入口**: 个人会员中心 → 我的项目 → [某项目] → 划拨积分到项目

**操作流程**：
1. 选择要划拨的项目
2. 输入划拨金额（需验证：不超过个人总余额）
3. 确认划拨
4. 积分从个人总账户扣除，增加到项目子钱包

**UI示例**：
```
┌──────────────────────────┐
│ 个人总积分: 10,000                    │
│ 项目子钱包: 2,000                     │
├────────────────────────────────┤
│ 划拨金额: [_______] 积分           │
│                                │
│ [确认划拨] [取消]                  │
└──────────────────────────────────┘
```

#### 4.3 成员积分分配（总导演在项目管理中操作）
**入口**: 项目管理 → 成员管理 → [某成员] → 分配积分额度

**操作流程**：
1. 项目子钱包显示可分配余额
2. 选择成员（或邀请新成员时设置）
3. 输入分配额度（需验证：不超过项目子钱包余额）
4. 确认分配
5. 积分从项目子钱包扣除，成员获得专属额度

**成员列表UI示例**：
```
┌──────────────────┐
│ 项目子钱包余额: 2,000 积分                  │
├──────────────────────────────────┤
│ 成员ID      姓名        已分配额度      操作            │
│ WF-10001   张三        500           [追加] [回收]    │
│ WF-10002   李四        300           [追加] [回收]    │
│ WF-10003   王五        0             [分配]        │
│                               │
│ [+ 邀请新成员]                        │
└────────────────────────────┘
```

#### 4.4 权限与约束

**总导演权限**：
- ✅ 从个人总账户划拨积分到项目子钱包
- ✅ 从项目子钱包分配积分给成员
- ✅ 回收成员未使用的积分（退回项目子钱包）
- ✅ 查看所有成员的积分使用情况

**成员权限**：
- ✅ 查看自己在该项目的专属额度
- ✅ 使用专属额度进行项目内消费
- ❌ 不能提现或转移到其他项目
- ❌ 不能查看项目子钱包总余额

**约束规则**：
1. 个人总积分 ≥ 已划拨到所有项目的积分之和
2. 项目子钱包余额 ≥ 已分配给所有成员的积分之和
3. 分配操作需实时校验余额，防止超额分配
4. 所有积分流转记录需保留审计日志

#### 验收标准
- [ ] 三级积分体系架构实现
- [ ] 总导演可从个人账户划拨积分到项目
- [ ] 总导演可在项目管理中给成员分配积分
- [ ] 余额校验机制正常，无法超额分配
- [ ] 成员可查看自己的专属额度
- [ ] 积分流水记录完整，可追溯
- [ ] 积分回收功能正常（可选）
