## 🎯 今日需求提炼（仅包含新增/优化部分）

### 需求1：项目管理模块整合优化 🔄

**优先级**: P1  
**类型**: 功能整合 + UI重构  
**背景**: 现有"项目设置"功能不完善，"项目管理"和"总导演驾驶舱"功能分散

#### 1.1 功能整合方案

**现状问题**：
- "项目管理"功能不完善（具体缺失功能待图片确认）
- "总导演驾驶舱"作为独立入口存在
- 数据仪表盘未整合到统一模块
- 用户需要在多个入口间切换，体验差

**整合方案**：
```
【统一入口】项目管理
├── 成员管理（核心）
│   ├── 邀请会员（通过ID）
│   ├── 成员列表
│   └── 积分分配
├── 数据仪表盘（整合原"总导演驾驶舱"功能）
│   ├── 项目概览
│   ├── 成员动态
│   └── 积分流水
└── 项目设置（完善现有功能）
    ├── 基本信息
    ├── 权限配置
    └── 其他设置
```

**重点**：
- 将"总导演驾驶舱"的所有功能迁移到"项目管理 > 数据仪表盘"二级菜单
- 原"总导演驾驶舱"入口废弃（避免功能重复）
- 统一使用"项目管理"这个名称

#### 1.2 导航结构优化

**新增顶部导航**：
```
┌───────────────────────────┐
│  [返回大厅]  [项目管理]    ...其他功能...         │
└──────────────────────────────────┘
```

**设计要点**：
- 两个按钮放在页面上方（header区域）
- "返回大厅"：全局导航，回到项目列表/首页
- "项目管理"：快速进入当前项目的管理界面
- 位置要醒目，方便用户快速切换

#### 验收标准
- [ ] "项目管理"和"总导演驾驶舱"功能合并完成
- [ ] 数据仪表盘作为二级菜单展示
- [ ] 顶部导航新增两个入口按钮
- [ ] 原"总导演驾驶舱"入口移除
- [ ] 所有功能可正常访问，无遗漏

### 需求2：会员ID功能优化 🆔

**优先级**: P1  
**类型**: 功能增强  
**背景**: 积分分配流程需要通过会员ID邀请成员

#### 2.1 业务流程（长腿叔叔说明）

```
步骤1: 个人积分划拨到项目子钱包
        ↓
步骤2: 在项目管理中邀请会员
        - 通过会员ID号查找
        - 每个会员设置一个ID号
        ↓
步骤3: 在项目管理页面进行成员积分分配
        - 给邀请的成员分配项目专属额度
```

#### 2.2 ID功能需求

**核心功能**：
1. **ID模板设置**
   - "ID号可以设置一个模板"
   - 推测：管理员可配置ID格式规则（如前缀、位数等）
   - 例如：WF-{6位数字}、USER-{8位数字} 等

2. **个人中心复制功能**
   - 用户在个人会员中心可以看到自己的ID
   - 提供"一键复制"功能（方便分享给项目总导演）

3. **ID邀请机制**（在项目管理中）
   - 总导演输入会员ID
   - 系统查找对应用户
   - 发送项目邀请
   - 被邀请用户接受后加入项目

### 需求3：积分分配流程完善 💰

**优先级**: P1  
**类型**: 功能完善（可能已有基础功能）  
**背景**: 长腿叔叔详细说明了三级积分分配体系

#### 3.1 积分流转架构

```
┌─────────────────┐
│      个人总积分池              │
│   (用户的积分总账户)            │
└──────────┬───────────┘
           │ ① 划拨
           ↓
┌───────────────────────┐
│    项目子钱包                │
│  (项目专属积分池)             │
│  (总导演管理)                │
└──────────┬──────────────┘
           │ ② 分配
           ↓
┌─────────────────┐
│   成员专属额度               │
│ (项目成员可使用的积分)         │
└─────────────────────────┘
```

#### 3.2 关键功能点

**① 个人积分划拨到项目**（已有功能？）
- 用户从个人总积分中划拨指定金额到某个项目
- 需要余额校验：不能超过个人总积分

**② 项目管理中的成员积分分配**（核心需求）
- **入口**：项目管理 > 成员管理
- **前置条件**：已通过会员ID邀请成员加入项目
- **操作**：总导演给每个成员分配项目专属额度
- **约束**：不能超过项目子钱包余额

- [ ] 项目子钱包余额实时展示
- [ ] 成员积分使用情况统计
