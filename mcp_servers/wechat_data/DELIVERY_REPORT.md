## 📋 项目概述

开发了一个完整的 MCP (Model Context Protocol) 服务，用于访问和查询微信聊天数据库。该服务为 Claude Code 提供了结构化的数据访问接口，支持联系人搜索、消息查询、群聊分析等功能。

### 核心价值

- **数据访问层**: 为 AI 提供标准化的微信数据访问接口
- **语义分析基础**: 支持基于聊天记录的需求自动识别
- **工作流集成**: 可与 kanban-doc 等工具配合，实现自动化任务管理
- **可扩展架构**: 易于添加新的查询工具和分析功能

## ✨ 功能清单

### 1. search_messages
**功能**: 全局搜索消息内容
**参数**:
- `keyword` (必需): 搜索关键词
- `days` (可选): 最近N天，默认7天
- `limit` (可选): 返回数量，默认50

**返回**: 消息列表（时间、发送者、内容、类型）

### 2. get_contact_messages
**功能**: 获取指定联系人的聊天记录
**参数**:
- `wxid` (必需): 微信ID
- `days` (可选): 最近N天，默认7天
- `limit` (可选): 返回数量，默认100

**返回**: 私聊消息列表

### 3. get_group_messages
**功能**: 获取群聊消息
**参数**:
- `group_wxid` (必需): 群聊ID
- `days` (可选): 最近N天，默认7天
- `limit` (可选): 返回数量，默认100

**返回**: 群聊消息列表（包含发送者信息）

### 4. search_by_time_range
**功能**: 按时间范围查询消息
**参数**:
- `start_date` (必需): 开始日期 (YYYY-MM-DD)
- `end_date` (必需): 结束日期 (YYYY-MM-DD)
- `keyword` (可选): 关键词过滤
- `limit` (可选): 返回数量，默认100

**返回**: 时间范围内的消息列表

### 5. get_contact_info
**功能**: 查询联系人信息
**参数**:
- `nickname` (可选): 昵称（模糊匹配）
- `wxid` (可选): 微信ID（精确匹配）
- `remark` (可选): 备注名（模糊匹配）

**返回**: 联系人详细信息（wxid、昵称、备注、类型）

### 6. get_all_groups
**功能**: 获取所有群聊列表
**参数**: 无

**返回**: 群聊列表（群ID、群名、成员数）

## 📖 使用指南

### 快速开始

1. **安装依赖**
```bash
./venv/Scripts/pip install mcp
```

2. **配置到 Claude Code**

编辑 `~/.claude/settings.json`:
```json
{
  "mcpServers": {
    "wechat-data": {
      "command": "python",
      "args": ["-m", "mcp_servers.wechat_data.server"],
      "cwd": "D:\\develoment_home\\project_home\\WeChatMsgArchive"
    }
  }
}
```

3. **重启 Claude Code**

4. **测试工具**
```python
# 搜索消息
mcp__wechat-data__search_messages({
    "keyword": "切歌",
    "days": 7
})

# 获取联系人信息
mcp__wechat-data__get_contact_info({
    "nickname": "三叶草"
})
```

### 使用场景

#### 场景 1: 需求自动识别
```python
# 1. 查询最近与客户的聊天
messages = get_contact_messages(wxid="wxid_xxx", days=7)

# 2. AI 分析消息内容，识别需求和 Bug
# 3. 自动创建 kanban 任务
```

#### 场景 2: 项目进度跟踪
```python
# 1. 搜索项目相关消息
messages = search_messages(keyword="syc-player", days=30)

# 2. 分析任务完成情况
# 3. 生成进度报告
```

#### 场景 3: 客户沟通分析
```python
# 1. 获取所有群聊
groups = get_all_groups()

# 2. 分析群聊活跃度
# 3. 识别重要客户和项目
```
